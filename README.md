# Vadym Zelenko — Portfolio

Personal website: about, skills, current work, selected projects and contacts.

Live: https://about-me-pi-five.vercel.app

## Pages

| Path | Content |
|---|---|
| `index.html` | Main page: introduction, work in progress, skills, contact |
| `projects.html` | Selected projects with links to live versions and source code |
| `resume-download/` | Printable résumé page |

## Stack

Static HTML, Tailwind CSS, GSAP scroll animations. No build step: the site can be served by any static host.

```bash
npx serve .
```
